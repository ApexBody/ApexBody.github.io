Important Guidelines & Operating Systems

  • Most coursework and assignments will require you to use Linux. If you purchase a Windows laptop, we will help you install Linux on it during the first week. Mac users do not need Linux.
  • ECE/D students should avoid MacBooks due to software compatibility issues.
  • Avoid Snapdragon X (or any ARM architecture chips) as Linux support is currently in very early stages.
  • Avoid MediaTek WiFi chips since they are not well supported on Linux.
  • Please carry a pendrive (Min 8GB) to install Linux (for Windows laptops only).
  • There is no strict requirement for graphics cards; GPU server access is provided by the college for research/project work when needed. Avoid purchasing a laptop solely for an RTX GPU. CPU, RAM, battery life, and build quality matter more.
  • Prefer business laptops (ThinkPad, ThinkBook, EliteBook, Latitude, ProBook) over gaming laptops in the same price range. A good laptop should comfortably last 4-5 years.
  • Check whether RAM and SSD are user-upgradeable before purchasing. An extended warranty (3 years) is highly recommended.
  • No additional software needs to be installed before coming to college; tools will be introduced as part of coursework.
  • If you already own a laptop that falls slightly below the specifications, there is no need to replace it immediately. First-semester coursework is light.
